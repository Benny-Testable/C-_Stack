# Database migrations

Executable EF Core migrations live with the API:

`backend/src/ScholarshipCMGroups.Api/Data/Migrations/`

They are generated by:

```bash
cd backend/src/ScholarshipCMGroups.Api
dotnet ef migrations add <Name>
```

[../schema/001-initial-schema.sql](../schema/001-initial-schema.sql) is the same initial model in T-SQL for operators who apply schema without the .NET toolchain.

Do not hand-edit generated `*.Designer.cs` or the snapshot; change the model and add a new migration instead.
